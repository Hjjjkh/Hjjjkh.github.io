Part 4.5：最短路径：Floyd-Warshall 算法

本文最后更新于 2025年11月15日 下午

引言：上帝视角的全局最短路径

在前面的文章中，我们学习了 Dijkstra 和 Bellman-Ford 算法，它们都解决了单源最短路径（Single-Source Shortest Path, SSSP）问题——即从一个固定的起点 s 到图中所有其他点的最短距离。这就像我们站在一个城市的某个地铁站，计算去往其他所有站点的最短时间。

但如果我们需要知道任意两个地铁站之间的最短时间呢？

一个朴素的想法是：对每个站点都运行一次 Dijkstra 算法。如果图中有 V 个节点，那么就需要运行 V 次。如果图是稠密的，Dijkstra（使用堆优化）的时间复杂度是 O(E log V)，总时间就是 O(V * E log V)。这在很多情况下效率不够高，而且 Dijkstra 还无法处理负权边。

Floyd-Warshall 算法（简称 Floyd 算法）应运而生。它以一种截然不同的、基于动态规划的思路，优雅地解决了所有节点对之间的最短路径（All-Pairs Shortest Path, APSP）问题。它就像给了我们一张全局交通图，上面标注了任意两点间的最短距离。

为什么 Floyd 算法如此重要？

  • 面试价值：Floyd 算法是动态规划思想在图论中的经典应用，代码极其简洁，面试中常被用来考察候选人对 DP 和图论的综合理解。
  • 学术与工程价值：在需要计算网络中任意两点间最短距离的场景，如网络路由、社交网络分析、交通流量规划等，Floyd 算法提供了一个简洁有效的解决方案。它还能检测图中是否存在负权环。

本文将带你从动态规划的本质出发，彻底理解 Floyd 算法的精髓。

背景知识：动态规划与邻接矩阵

要理解 Floyd，你需要具备以下两个前置知识：

  1. 动态规划 (Dynamic Programming)：将一个大问题分解成若干个子问题，通过求解子问题的最优解来推导出原问题的最优解。核心是状态定义和状态转移方程。
  2. **邻接矩阵 (Adjacency Matrix)**：一种存储图的方式。对于一个有 V 个节点的图，我们用一个 V x V 的矩阵 dist 来表示，其中 dist[i][j] 存储了从节点 i 到节点 j 的边的权重。如果 i 和 j 之间没有直接相连的边，则 dist[i][j] 为无穷大（∞），而 dist[i][i] 为 0。

Floyd 算法正是基于邻接矩阵和动态规划思想来构建的。

详细算法原理

1. 算法的“直觉”：“中转站”思想

Floyd 算法的核心思想非常直观：从 i 到 j 的最短路径，要么是直接从 i 走到 j，要么是经过若干个“中转站”。

算法的巧妙之处在于，它不是一次性考虑所有可能的中转站，而是逐步放开中转站的限制。

  • 第一步：我们只允许从 0 号节点中转。此时，对于任意两点 i 和 j，它们的最短路径是 dist(i, j) 和 dist(i, 0) + dist(0, j) 中的较小值。
  • 第二步：我们允许从 0 号和 1 号节点中转。此时，i 到 j 的最短路径，是在上一步结果的基础上，再考虑是否经过 1 号节点会更短。
  • …
  • 第 k 步：我们允许从 0 到 k-1 号节点中转。
  • 最后一步：我们允许所有节点（0 到 V-1）作为中转站。此时，我们就得到了任意两点 i 和 j 之间的全局最短路径。

2. 严谨原理：动态规划的状态定义

Floyd 算法的本质是一个动态规划。让我们来定义它的状态：

dp[k][i][j]：表示在只允许使用编号从 0 到 k 的节点作为中转站时，从节点 i 到节点 j 的最短路径长度。

状态转移方程

当我们计算 dp[k][i][j] 时，我们已经知道了 dp[k-1][i][j]（即只允许 0 到 k-1 作为中转站时的最短路径）。现在，我们多了一个可以使用的中转站：节点 k。

从 i 到 j 的路径，在允许 0 到 k 中转的情况下，只有两种可能：

  1. 不经过 节点 k：那么最短路径就是之前已经求出的、只使用 0 到 k-1 作为中转站的最短路径，即 dp[k-1][i][j]。
  2. 经过 节点 k：那么路径一定是 i → ... → k → ... → j。由于我们求的是最短路径，这条路径必然是由 i 到 k 的最短路径和 k 到 j 的最短路径拼接而成。并且，这两段路径都只使用了 0 到 k-1 作为中转站。所以，这条路径的长度是 dp[k-1][i][k] + dp[k-1][k][j]。

图示：状态转移

综合这两种情况，我们取其中的较小值，就得到了状态转移方程：

dp[k][i][j] = min(dp[k-1][i][j], dp[k-1][i][k] + dp[k-1][k][j])

空间优化：状态压缩

观察状态转移方程，我们发现计算第 k 层的 dp 值，只依赖于第 k-1 层。这提示我们可以进行状态压缩（也叫“滚动数组”）。

我们可以去掉 k 这一维度，直接在二维数组上更新：

dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

这里 dist 数组同时扮演了 dp[k-1] 和 dp[k] 的角色。需要注意的是，为了保证 dist[i][k] 和 dist[k][j] 是 k-1 轮更新后的结果，**k 必须在最外层循环**。

步骤分解 (Step-by-step)

  1. 初始化：创建一个邻接矩阵 dist。dist[i][j] 存储边 (i, j) 的权重。如果 i 和 j 不直接相连，则为 ∞。dist[i][i] 为 0。
  2. 外层循环：遍历所有可能的中转站 k，从 0 到 V-1。
  3. 中层循环：遍历所有可能的起点 i，从 0 到 V-1。
  4. 内层循环：遍历所有可能的终点 j，从 0 到 V-1。
  5. 状态更新：在循环体内，执行松弛操作：dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])。
  6. 结束：三层循环结束后，dist[i][j] 中存储的就是从 i 到 j 的最短路径长度。

动画式案例

假设我们有如下带权有向图：

图示：一个包含 4 个节点的图

  • 节点: 0, 1, 2, 3
  • 边: (0,1,5), (0,3,10), (1,2,3), (2,3,1)

1. 初始化 dist 矩阵 (k=-1)

2. k = 0 (允许从 0 中转)

  • dist[i][j] 和 dist[i][0] + dist[0][j] 比较。由于没有边指向 0，dist[i][0] 都是 ∞ (除了 i=0)，所以矩阵不变。

3. k = 1 (允许从 0, 1 中转)

  • 检查 dist[i][1] + dist[1][j]。
  • 关注路径 0 -> 1 -> 2：dist[0][2] 原为 ∞。新路径 dist[0][1] + dist[1][2] = 5 + 3 = 8。更新 dist[0][2] = 8。

4. k = 2 (允许从 0, 1, 2 中转)

  • 检查 dist[i][2] + dist[2][j]。
  • 关注路径 1 -> 2 -> 3：dist[1][3] 原为 ∞。新路径 dist[1][2] + dist[2][3] = 3 + 1 = 4。更新 dist[1][3] = 4。
  • 关注路径 0 -> 1 -> 2 -> 3：dist[0][3] 原为 10。新路径 dist[0][2] + dist[2][3] = 8 + 1 = 9。更新 dist[0][3] = 9。

5. k = 3 (允许所有节点中转)

  • 检查 dist[i][3] + dist[3][j]。没有边从 3 出发，矩阵不变。

最终，我们得到了所有节点对之间的最短路径矩阵。

复杂度推导过程

时间复杂度

Floyd 算法的结构非常清晰，就是三层嵌套循环。

  • **外层循环 (k)**：从 0 到 V-1，执行 V 次。
  • **中层循环 (i)**：从 0 到 V-1，执行 V 次。
  • **内层循环 (j)**：从 0 到 V-1，执行 V 次。

总的执行次数 T(V) = V * V * V = V³。

因此，时间复杂度为 **O(V³)**，其中 V 是图中节点的数量。

空间复杂度

算法需要一个二维数组 dist 来存储所有节点对之间的距离。

  • 矩阵的大小是 V x V。

因此，空间复杂度为 **O(V²)**。

优势 / 劣势 / 易错点

优势

  1. 代码简洁：三层循环的核心代码非常优美，易于实现。
  2. 功能强大：可以一次性计算出所有节点对之间的最短路径。
  3. 支持负权边：与 Dijkstra 不同，Floyd 可以正确处理带有负权边的图。
  4. 可检测负权环：通过检查 dist[i][i] 是否小于 0，可以方便地判断图中是否存在负权环。
  5. 适用于稠密图：在稠密图中，E 接近 V²，V 次 Dijkstra 的复杂度 O(V * E log V) 接近 O(V³ log V)，此时 O(V³) 的 Floyd 更具优势。

劣势

  1. 时间复杂度高：O(V³) 的复杂度使其不适用于节点数量非常庞大的图（例如，V > 500 时就可能非常慢）。
  2. 空间复杂度高：O(V²) 的空间开销对于大规模图也是一个挑战。

易错点

  1. 循环顺序错误：**k 必须在最外层循环！** 如果将 k 放在内层，算法的逻辑就不再是“逐步放开中转站”，得到的结果将是错误的。
  2. 无穷大的表示：在实现中，需要用一个足够大的数来表示无穷大。注意，这个数不能大到在相加时发生整数溢出。

适用场景

  1. **求解所有节点对之间的最短路径 (APSP)**：这是 Floyd 算法的经典应用场景。
  2. 图中节点数量较少：通常在 V 小于几百的规模下使用。
  3. 存在负权边但无负权环的图：这是它相较于 Dijkstra 的主要优势之一。
  4. 检测负权环：一个简单有效的负权环检测方法。
  5. 传递闭包问题：通过稍加修改，Floyd 算法可以用来计算图的传递闭包（即判断任意两点 i 和 j 是否连通）。

扩展算法 & 进阶方向

  1. 路径记录：标准的 Floyd 算法只计算了最短路径的长度。我们可以额外维护一个 path 矩阵，path[i][j] 记录从 i 到 j 的最短路径上 j 的前一个节点，从而可以回溯出完整的路径。
  2. Johnson 算法：对于稀疏图（E 远小于 V²）且存在负权边的情况，Johnson 算法是更高效的 APSP 解决方案。它通过一次 Bellman-Ford 和 V 次 Dijkstra，将时间复杂度优化到 O(V * E log V)。

总结

Floyd-Warshall 算法以其简洁的代码和强大的功能，在图论算法中占有重要地位。它不仅是解决多源最短路径问题的利器，更是动态规划思想在图论中应用的典范。

本文核心要点

✅ 核心思想：基于动态规划，通过“中转站”逐步放开限制来求解最短路径。
✅ 状态转移方程：dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])。
✅ 循环顺序：中转站 k 必须在最外层循环。
✅ 复杂度：时间复杂度 O(V³)，空间复杂度 O(V²)。
✅ 适用性：适用于节点数不多的稠密图，可以处理负权边并检测负权环。
